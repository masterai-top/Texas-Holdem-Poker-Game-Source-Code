# 安全、随机数与合规

扑克服务器涉及账号、牌局状态和可能的订单数据，部署前必须进行独立安全审查。

## 技术检查

- 使用适合安全场景的随机数来源并避免可预测种子
- 洗牌和发牌逻辑由服务端控制并可审计
- 校验每个行动的牌桌、玩家、状态和顺序
- 对重放、重复请求、越权和并发竞争进行测试
- 传输加密，密钥不写入源码
- 日志脱敏并设置访问权限与保留期限
- 依赖库定期扫描漏洞

## 合规检查

扑克软件在不同地区受到不同监管。商业部署前应咨询当地专业人士，确认游戏、竞赛、虚拟货币、支付、年龄限制、隐私和数据保留要求。开源许可证不代表自动取得商业运营许可。

发现安全问题时，不要公开敏感利用细节，请使用仓库维护者提供的私下报告渠道。
