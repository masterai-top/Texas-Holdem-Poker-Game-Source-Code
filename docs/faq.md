# 常见问题

## 这是德州扑克完整源码吗？

当前公开仓库可见内容以 C++ 服务端、Tars 协议、截图和视频为主。是否包含客户端、数据库、管理后台及其他商业组件，请以实际文件和授权范围为准。

## 如何下载？

在 [仓库首页](https://github.com/masterai-top/Texas-Holdem-Poker-Game-Source-Code) 点击 **Code → Download ZIP**，或使用 Git 克隆。

## 为什么不能直接编译？

Makefile 可能依赖特定 Tars、编译器、库版本或本机路径。请先查看 [构建指南](./build-guide.md)。

## 可以直接商业运营吗？

不能仅凭公开仓库作出判断。需要确认许可证、完整组件、安全审计、第三方资源授权以及运营地区法律要求。

## 是否包含扑克 AI？

当前首页可见文件不足以确认独立扑克 AI 模块，因此不建议使用 `poker-ai` Topic 或在 README 中宣称已支持 AI。
