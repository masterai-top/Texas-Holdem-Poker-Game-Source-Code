# 德州扑克牌局流程与状态管理

多人扑克服务端需要把玩家行为约束在明确的牌局状态内。仓库中的 `gamestation.cpp`、`Processor.cpp`、`sitdown.cpp` 和 `standup.cpp` 是理解流程的主要入口。

## 建议梳理的状态

1. 玩家进入房间并取得牌桌信息。
2. 玩家坐下并满足开局条件。
3. 服务端初始化牌局与玩家状态。
4. 发牌及各轮行动按顺序推进。
5. 结算结果并记录牌局数据。
6. 玩家继续、站起或离开。

所有行动都应由服务端校验当前状态、行动玩家、下注范围和请求序号。断线重连、重复请求、超时和并发操作需要单独测试。本文只描述阅读和测试方向，具体规则以源码实现为准。
